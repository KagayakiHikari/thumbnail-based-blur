# 縮小画像ぼかしの技術仕様

[中文](blur-effect.md) · [English](blur-effect.en.md) · **日本語**

本モジュールは縮小処理、分離可能なボックス畳み込み、色変換、キャッシュ、座標による再サンプリングを実装します。入力はデコード済み画像、写像矩形、数値パラメーターで、出力は Canvas の画素データです。中核の計算は文字マスクから独立しています。

## 入力の写像

元画像を Iw × Ih、写像寸法を W × H、長辺上限を M とします。寸法は有限の正数が必要です。

```text
q = max(W / Iw, H / Ih)
dw = Iw × q; dh = Ih × q
x = (W - dw) × position.x; y = (H - dh) × position.y
s = min(1, M / max(W, H))
w = max(1, ceil(W × s)); h = max(1, ceil(H × s))
sx = w / W; sy = h / H
```

coverRect() は矩形を覆う写像を計算します。位置成分は [0,1] の範囲です。Canvas drawImage() で縮小し、丸めを考慮した実際の比率 sx、sy を別々に使います。補間はブラウザーに依存します。透明入力は不透明色 #111827 に合成してから処理します。

## 畳み込みと境界

boxBlur() は長さ 4wh の RGBA 配列、[0,512] の整数半径 r、[1,10] の整数反復回数を受け取ります。ブラウザーモジュールは 3 回反復します。

```text
r = blur == 0 ? 0 : max(1, round(blur × s × 0.58))
k = 2r + 1
e(i,n) = min(n-1, max(0,i))
S(x) = sum(C(e(x+j,w), y), j=-r..r)
S(x+1) = S(x) - C(e(x-r,w), y) + C(e(x+r+1,w), y)
H(x,y) = S(x) / k
```

各回で水平方向、続いて同じ漸化式で垂直方向を平均化します。範囲外では端の画素を繰り返します。各方向の結果を Uint8ClampedArray に書き込み、バイト値への丸めと範囲制限が生じます。RGB は個別に計算し、alpha は 255 です。3 回の処理は平滑化カーネルの近似です。0.58 は近似係数で、ガウス標準偏差への厳密な変換ではありません。厳密なガウス畳み込みや CSS ぼかしとは同一ではありません。

## 色変換

チャンネルを C、彩度を a、明度を b、塗り色を T、混合率を t、ゲインを g とします。

```text
L = 0.2126R + 0.7152G + 0.0722B
F(C) = clamp((L + a × (C - L)) × b, 0, 255)
O(C) = ((1-t) × F(C) + t × T(C)) × g
```

型付き配列が出力をバイト値に変換し、alpha は 255 になります。符号化されたチャンネル値を直接使い、線形光への変換は行いません。ブラウザーフィルターとの画素単位の一致は保証しません。

## キャッシュの状態

prepare() のキーは画像 URL、元画像寸法、写像寸法、全処理パラメーター、無効化番号を含みます。一致時は画素を再利用します。写像原点は更新しますがキーに含めません。invalidate() は番号を増やしてキーを消去します。同じ URL の内容が変わった場合は明示的に呼び出します。

読み取り成功時は ready です。失敗時は汚染された Canvas をリセットし、tint で塗りつぶして fallback にします。代替色の alpha は保持します。失敗結果もパラメーター変更または無効化までキャッシュします。buildCount は生成回数で、フレームレートではありません。

## 出力とマスク

bounds と rect は同じビューポート座標を使います。出力寸法は ceil(rect.width × dpr)、ceil(rect.height × dpr) です。原点は (bounds.left-rect.left, bounds.top-rect.top) × dpr、描画寸法は写像寸法に dpr を乗じた値です。

毎回消去してから描画し、写像範囲外は透明にします。任意の alpha マスクは destination-in で合成します。既定 DPR の上限は 2 です。出力時に畳み込みや画像符号化は行いません。

attachFrostedText() は独立した任意の字形ラスタライズアダプターです。DOM Range で文字位置を取得してマスクを生成し、ぼかし計算には関与しません。複雑な合字、結合文字、双方向文字の完全な整形は保証しません。

## 計算量と制約

反復 p 回、w × h 画素、半径 r に対し、窓の初期化と走査は O(p × (wh + r(w+h))) です。半径と回数が固定なら概ね O(wh) です。作業配列 3 本は 12wh バイトで、入力、ImageData、Canvas 領域が別途必要です。補助空間全体は O(wh) です。

メインスレッドで処理し、Worker や GPU 計算は実装していません。キャッシュは反復畳み込みを減らしますが、出力の再サンプリングと合成負荷は残ります。クロスオリジン読み取りには CORS 許可が必要です。明示された画像を処理し、ブラウザーの合成シーンは取得しません。固定フレームレート、ブラウザー間の画素一致、全フォント動作は未検証です。
