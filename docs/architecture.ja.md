# モジュール構成

[中文](architecture.md) · [English](architecture.en.md) · **日本語**

| モジュール | 責務 |
| --- | --- |
| src/pixels.js | cover 写像、RGBA スライディングウィンドウ畳み込み、色変換 |
| src/thumbnail-blur.js | 入力検証、キャッシュキーと無効化、Canvas 出力、任意のマスクアダプター |
| demo/app.js | パラメーター設定、画像デコード、出力の調整 |
| demo/i18n.js | 三言語辞書と言語選択 |
| scripts/ | ローカル HTTP サーバーと静的ファイルのビルド |
| tests/ | 独立した参照畳み込み、キャッシュ状態、翻訳整合性の確認 |

データフロー：デコード済み画像 → cover 写像と縮小 → 3 回のボックス畳み込み → 色変換 → キャッシュ → 座標による再サンプリング → 任意の alpha マスク。

中核モジュールはデモから独立しています。呼び出し側がリソース準備、出力矩形、更新を管理します。画素キャッシュと字形マスクの状態は独立しており、出力位置の変更だけではぼかしキャッシュの再生成は不要です。

数式、境界、計算量は [技術仕様](blur-effect.ja.md) を参照してください。
