# 検証範囲

[中文](verification.md) · [English](verification.en.md) · **日本語**

構文確認、9 件の自動テスト、静的ビルドを行います。独立した単純畳み込みとの照合、境界半径、cover 写像、一定色と混色端点、入力拒否、DOMRect のプロトタイプ座標、キャッシュ一致と無効化、読み取り失敗時の代替処理、翻訳キーと文書パスを確認します。

```sh
npm run check
npm test
npm run build
```

キャッシュテストは制御された Canvas 代替を使用し、実際の CORS 結合テストの代わりにはなりません。実機フレームレート、ブラウザー間の画素一致、複雑な文字整形は未検証です。
